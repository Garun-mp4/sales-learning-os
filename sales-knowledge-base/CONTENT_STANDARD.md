# Стандарт учебных материалов

1. **Одна единица — один ID**. Заголовок, модуль и группа совпадают с исходным реестром, связи обратимы.
2. **Объяснить термин**: смысл, применимость, ограничения и разница со смежными терминами. Не маскировать пустоту объёмом текста.
3. **Применить**: конкретный алгоритм письменного действия с проверяемыми входами и выходами.
4. **Показать пример**: бизнес-задача, альтернативы, слова клиента, расчёт или проектный документ; явно помечать все придуманные данные.
5. **Проверить понимание**: самостоятельный ответ и артефакт; не считать чтение компетенцией.
6. **Источники**: ID и прямая ссылка; библиографию с главами и страницами приводить только после проверки издания.
7. **Этика**: добровольность, запрет фиктивных кейсов, неправомерной рассылки, ложной статистики, давления и выдуманных обязательств.
8. **Формат**: Markdown UTF-8; YAML front matter; русские пояснения, английские аббревиатуры при первом употреблении расшифровывать.
9. **Редакторский контроль**: материал с `editorial_draft` не считается прошедшим независимую фактологическую экспертизу.

Сложные главы следует развивать глубже начального конспекта: примеры с развёрнутыми решениями, диаграммы, расчёты, библиография по конкретным главам. Начальный атомарный конспект — не замена всем специализированным учебникам.
