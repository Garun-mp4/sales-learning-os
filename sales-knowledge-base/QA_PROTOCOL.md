# Протокол качества

## Автоматические проверки

- [ ] Все 22 директории модулей существуют.
- [ ] Все 336 уроков и 72 практики присутствуют; имена и ID уникальны.
- [ ] Все ссылки на локальные `.md` существуют.
- [ ] Каждый учебный файл имеет метаданные, источники, практику или критерий результата.
- [ ] В теории нет пустых секций; есть объяснение, пример, вопросы, критерии освоения.
- [ ] В практике указан артефакт, шаги и рубрика оценки.

## Редакторские проверки — нужны по каждому файлу

- [ ] Утверждения действительно верны и не противоречат первоисточнику.
- [ ] Примеры и числовые расчёты корректны, гипотезы помечены.
- [ ] Материал достаточен для самостоятельного освоения, без необъяснённых терминов.
- [ ] Источники подтверждают именно эту тему, а не только близкое направление.
- [ ] Юридические нормы не устарели и относятся к нужной юрисдикции.
- [ ] Видео изучено, а не только его название/описание.
- [ ] Чужие тексты не скопированы и корректно атрибутированы.
- [ ] Проверяющий решил упражнение по заявленным критериям.

**Выполнение автоматических проверок не заменяет редакторские.** Итоговый статус до такого аудита — `editorial_draft`.

- **Структура:** 22 модуля, 336 файлов теории, 72 файла практики, 6 каталогов источников и 10 системных документов — 446 Markdown-файлов.
- **Машинные проверки:** YAML-поля, уникальность ID, существование всех локальных Markdown-ссылок, обязательные разделы уроков и упражнений — **0 найденных ошибок**.
