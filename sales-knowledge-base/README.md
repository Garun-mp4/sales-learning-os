# Sales OS — база знаний по текстовым продажам

Версия: редакционный комплект 2026-10-08. Исходник структуры: `index.html` (проверены 22 модуля, 336 теоретических пунктов, 72 задания).

## Для чего создана база

Самостоятельно изучать продажи от нуля до профессиональной практики. Все реальные коммуникации — только через разрешённые текстовые каналы: Telegram, WhatsApp, MAX, email. **Холодных звонков в программе нет.** Сквозной продукт — разработка сайтов и IT-решений; навыки переносимы на другие отрасли.

## Что читать

1. Открой `ROADMAP_MAP.md` и выбери модуль.
2. Прочитай `modules/NN-slug/00-module.md`.
3. Пройди атомарные уроки в порядке ID.
4. Выполни упражнения из `practice/`, оцени результат по рубрике.
5. Для дополнительной проверки исходных идей смотри реестр `sources/`.

## Важная маркировка качества

`status: editorial_draft` означает **структурированный редакционный материал, не прошедший независимую экспертную рецензию**. Весь массив имеет рабочий характер, даже если ссылки существуют и автоматические проверки успешны. Не следует обещать, что все 336 конспектов фактически сопоставлены с полными текстами книг или видео. Платные книги не были загружены и полностью прочитаны; полные YouTube-транскрипты не получены. Источники используются как проверенные места для дальнейшего изучения и проверки, не как построчные цитаты.

Материалы по праву, платформам, налогам и договорам требуют актуальной проверки применительно к стране пользователя и заказчика, модели бизнеса и дате отправки сообщения. Не являются юридической консультацией.

## Метаданные

Каждый файл содержит YAML front matter: `id`, `title`, `module`, `kind`, `level`, `group`, `status`, `updated`, `sources`, `related_practice`. Стабильный ключ урока: `01-001`; ключ практики: `01-P01`.
