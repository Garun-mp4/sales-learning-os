# Глоссарий

| Термин | Рабочее определение |
|---|---|
| Lead | Идентифицированная возможная организация/контакт, ещё не квалифицированная сделка |
| ICP | Профиль организации, для которой предложение наиболее релевантно |
| Buyer Persona | Типовая роль и контекст участника покупки, не стереотип личности |
| JTBD | Задача или прогресс, ради которого человек выбирает решение |
| Prospect | Проверенный потенциальный покупатель, соответствующий гипотезе |
| Opportunity | В CRM — возможная сделка с конкретной задачей и процессом |
| Discovery | Процесс прояснения текущей ситуации, потребности и критериев результата |
| SPIN | Situation, Problem, Implication, Need-Payoff — типы вопросов |
| BANT | Budget, Authority, Need, Timeline — факторы квалификации |
| MEDDPICC | Metrics, Economic Buyer, Decision Criteria/Process, Paper Process, Pain, Champion, Competition |
| USP / УТП | Обоснованное отличие предложения от альтернатив |
| CVP | Customer Value Proposition — объяснение полезного результата для клиента |
| CTA | Call to Action — один понятный следующий шаг |
| ROI | Отношение чистой выгоды к затратам (формула зависит от принятой модели) |
| TCO | Полная стоимость владения, внедрения и обслуживания |
| CAC | Затраты на приобретение нового клиента |
| LTV | Оценка суммарной экономической ценности отношений с клиентом |
| BATNA | Лучшая реальная альтернатива отсутствию сделки |
| ZOPA | Возможная область согласованных условий между сторонами |
| SOW | Scope of Work — состав и рамки выполняемых работ |
| Scope Creep | Неконтролируемое расширение согласованного состава проекта |
| CSAT | Показатель удовлетворённости по выбранному вопросу/шкале |
| NPS | Показатель ответов на вопрос о вероятности рекомендации, не эквивалент роста |
| Win Rate | Доля выигранных сделок среди закрытых с заданным определением |
| CRM | Система учёта организаций, контактов, сделок и действий |
| RFP | Request for Proposal — запрос предложений по требованиям |
| MVP | Минимальный продукт для проверки ключевой гипотезы |
