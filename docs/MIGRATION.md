# Перенос пользовательского прогресса

Формат первоначального экспорта: `sales-os-roadmap-v1`, JSON `{format,checks,notes}`. Форматы `sales-os-v2` (version 2) и `sales-os-v3` (version 3) также принимаются для импорта. Текущий формат резервной копии — `sales-os-v4` (version 4): все поля v3 и `trainerSessions` — сессии тренажёра с версией/снимком сценария, историей действий, собственным текстом, черновиком и отметкой восстановимого удаления. Старые копии получают пустые сессии, текущая история перед replace доступна в точке восстановления.

M2 не меняет IndexedDB schema v3: сессии добавлены в существующий объект состояния, отдельный store не нужен. Поддерживаются до 100 сессий, включая удалённые, до 40 действий на сессию, 6 000 символов на ответ и суммарно 3 млн символов сериализованных сессий. Превышение лимита отклоняется до записи без обрезания истории. Общий лимит импортируемого файла остаётся 8 MB. Неподдерживаемые будущие форматы отклоняются. Backup v4 нельзя импортировать в старую версию приложения, которая понимает только v3; сначала обновите приложение.

При merge одинаковые сессии дедуплицируются. Разные снимки с одинаковым ID сохраняются отдельными попытками с устойчивым производным ID; повторный импорт не добавляет копии того же конфликта. Конкурентные изменения живой попытки создают отдельную версию с `conflictOf`. Снимки старых сценариев не заменяются текущими: завершённые попытки читаются и сравниваются, несовместимая активная попытка остаётся доступна для чтения и предлагает начать новую.

Карта: `t-mi-ti-ii` → `NN-NNN`, `p-mi-li` → `NN-PNN`. Файл `src/generated/content-manifest.json` хранит словарь `legacyMap` на 408 ключей. В новой версии: старая отметка теории → `theory_completed`; практика → `self_reviewed` (самоотметка), **не** `mastered`/внешняя аттестация. Старые заметки к модулю → `NN-MODULE`. IndexedDB имеет schema v3 с отдельными хранилищами состояния, заметок и точек восстановления; миграция сохраняет существующую базу, а незавершённый импорт не заменяет текущие данные. Локальный snapshot-конверт `sales-os-local-v2` — внутренний формат localStorage и не равен переносимому backup `sales-os-v2`.

Из-за разных browser origins старый сайт, открытый через `file://`, не может передать localStorage веб-сайту автоматически. Пользователь вручную экспортирует JSON в старом `index.html`, затем выбирает импорт в Настройках. Preview показывает состав и формат до записи. Replace создаёт восстанавливаемую локальную точку возврата; merge объединяет несопоставленные записи, не дублирует попытки и сохраняет конфликтующие заметки отдельными блоками. Экспорт и восстановление остаются только на устройстве.
