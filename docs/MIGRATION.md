# Перенос пользовательского прогресса

Формат первоначального экспорта: `sales-os-roadmap-v1`, JSON `{format,checks,notes}`. Промежуточный формат `sales-os-v2` (version 2) также принимается для импорта. Текущий формат резервной копии — `sales-os-v3` (version 3): статусы уроков и практик, закладки, заметки, черновики/попытки практики, очередь повторения, её история, последняя позиция и метаданные экспорта.

Карта: `t-mi-ti-ii` → `NN-NNN`, `p-mi-li` → `NN-PNN`. Файл `src/generated/content-manifest.json` хранит словарь `legacyMap` на 408 ключей. В новой версии: старая отметка теории → `theory_completed`; практика → `self_reviewed` (самоотметка), **не** `mastered`/внешняя аттестация. Старые заметки к модулю → `NN-MODULE`. IndexedDB имеет schema v3 с отдельными хранилищами состояния, заметок и точек восстановления; миграция сохраняет существующую базу, а незавершённый импорт не заменяет текущие данные. Локальный snapshot-конверт `sales-os-local-v2` — внутренний формат localStorage и не равен переносимому backup `sales-os-v2`.

Из-за разных browser origins старый сайт, открытый через `file://`, не может передать localStorage веб-сайту автоматически. Пользователь вручную экспортирует JSON в старом `index.html`, затем выбирает импорт в Настройках. Preview показывает состав и формат до записи. Replace создаёт восстанавливаемую локальную точку возврата; merge объединяет несопоставленные записи, не дублирует попытки и сохраняет конфликтующие заметки отдельными блоками. Экспорт и восстановление остаются только на устройстве.
