# M2 — тренажёр переписки с клиентом

Дата: 2026-10-09. Область: только M2 из `FEATURE_ROADMAP.md`; M3–M8 не реализовывались. Инженерная готовность и независимая редакционная приёмка разделены.

## Пользовательский сценарий

Откройте «Тренажёр переписки» в навигации → выберите ситуацию → начните попытку → запишите собственный ответ и выберите действие → прочитайте ответ учебного клиента → завершите диалог → изучите разбор → повторите другой подход и сравните попытки.

Доступны шесть ситуаций:

| ID | Ситуация |
| --- | --- |
| price-context | Цена без контекста |
| too-expensive | «Это дорого» |
| proposal-silence | Молчание после предложения |
| competitor | Сравнение с конкурентом |
| unclear-need | Неопределённая потребность |
| extra-work | Бесплатная дополнительная работа |

В каждом графе четыре содержательные точки выбора, 12 действий и четыре конечных узла. Согласование следующего шага, риск невыполнимого обещания, отказ клиента и корректное завершение контакта не объявляются гарантией сделки. Поспешный ответ можно пересмотреть в отдельной ветке; ранний отказ может завершить разговор до прохождения всех точек.

Свободный текст не определяет ветку и не оценивается по словам. Объяснение привязано к выбранному действию. Итог содержит сильные решения, упущения, историю и ссылки на практики курса. Сравнение показывает две завершённые попытки одного сценария с исходными версиями; не начисляет баллы за изменение текста или действия.

## Сохранность и ограничения

- Единый user-store, IndexedDB schema v3 без нового хранилища; backup повышен до `sales-os-v4`. Импорт v1/v2/v3/v4, merge/replace и точки восстановления сохраняются.
- Каждая сессия хранит устойчивый ID, версию и полный снимок графа, последовательность действий и текстов, черновик, ревизию и дату удаления. Завершённая история не меняется при обновлении контента. Несовместимая активная версия доступна для чтения и предлагает новую попытку.
- Автосохранение не блокирует поле ввода. Правка во время медленной записи сохраняется следующей версией; отправка блокируется на время перехода и не дублируется повторным нажатием. Несохранённые изменения вызывают предупреждение при выходе; есть явное действие «Сохранить и вернуться».
- Конфликт двух вкладок создаёт отдельную попытку; оба текста остаются в истории. Импорт конфликтующих снимков также сохраняет обе версии и дедуплицирует повторный импорт.
- Удаление мягкое, без необратимого стирания; восстановление доступно в истории и сохраняется после reload/backup. Удалённые записи входят в лимит и резервные копии.
- Лимиты: 100 сессий, 40 действий в каждой, 6 000 символов на ответ, 3 млн символов всех сериализованных сессий; общий импорт до 8 MB. Превышение отклоняется без обрезания. При достижении лимита новая попытка не создаётся; архивирование и долговременное управление большими историями потребуют отдельного расширения.
- При недоступном постоянном хранилище показано предупреждение и доступен экспорт прямо на экране, без перехода, теряющего временную память. Кнопка возврата остаётся на месте до надёжного сохранения; можно скачать копию и затем самостоятельно выйти.
- Работа локальная: backend, облачной синхронизации, AI и отправки сообщений нет. Публичный поисковый индекс курса не менялся; каталог доступен через навигацию. Личные сессии исключены из Pagefind.

## Проверка

Финальные результаты: `npm run lint`, `npm run check` (0 errors/warnings, три прежние deprecated hints), обе сборки, static и offline gates — PASS. Astro сформировал 489 маршрутов и 1 031 offline-ресурс; Python — 488 документов и 511 offline-ресурсов. Публичный индекс курса сохранил 467 записей.

Общий адресный Playwright-прогон на Astro production preview: **48/48** (`sales-os`, `offline-pack`, `practice-feedback`, `trainer`). На Python fallback набор M2: **8/8**, включая медленную запись и полный offline-пакет. `npm run test:quality` и `npm run test:fallback` также прошли в ходе реализации; после финальных исправлений повторены обе сборки, линтер, типы, static/offline и адресные браузерные тесты. Найденная регрессия обработки квоты устранена и прошла повторную проверку существующего теста без изменения его ожиданий.

`npm run test:trainer` проверяет шесть графов и все 78 полных путей, отсутствие циклов, пропущенных переходов и недостижимых узлов, валидность истории и версий. Python-валидатор проверяет исходные графы и ссылки при обеих сборках. HTML-подобный пользовательский текст выводится через `textContent`.

Адресные браузерные сценарии: `tests/e2e/trainer.spec.ts`. Проверяются шесть сценариев, ветка исправления, корректный отказ, resume, двойная отправка, сравнение, удаление/восстановление, реальный backup round trip v4, конфликт вкладок и merge, устаревшая активная версия, отклонение повреждённых/будущих копий, отказ хранилища, медленная запись, offline и адаптивность.

Матрица интерфейса: light/dark × 320/375/390/768/1440 CSS px. Снимки: `docs/screenshots/m2-trainer/`. Встроенный браузер использован для проверки реального интерфейса; мобильные снимки дополнительно просмотрены отдельно.
