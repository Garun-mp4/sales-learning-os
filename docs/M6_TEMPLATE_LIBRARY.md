# M6 — личная библиотека рабочих шаблонов

Статус: **завершён** · 9 октября 2026

Личная библиотека встроена в `/library/templates/`. Она дополняет публичный справочник, сохраняя его неизменным: действие «Создать свой вариант» сохраняет отдельную копию с исходным текстом, названием источника, его ID и редакционной версией. Более позднее обновление справочника не переписывает такую копию.

Пользователь может создать шаблон с нуля, взять один из пяти стартовых текстов или скопировать абзац из публичного справочника. В каталоге есть поиск по названию, тексту, заметкам и тегам, пять рабочих категорий и «Другое», избранное и обратимый архив. Архивация сохраняет все версии; окончательного удаления в интерфейсе нет.

Переменные — только `{{service}}`, `{{client}}`, `{{context}}` и `{{next_step}}`. Значения подставляются как обычный текст, повторяющиеся маркеры заменяются все сразу. Неизвестный, незакрытый или пустой маркер и старые пометки в квадратных скобках блокируют копирование, но пользователь может сохранить и отредактировать такой черновик. HTML и выражения не исполняются. При запрете Clipboard API готовое значение появляется в выделяемом поле для ручного копирования; копирование никогда не отправляет сообщение.

У шаблона хранятся пояснение об уместном применении и личная заметка о фактическом результате. Они не обозначаются как показатели конверсии. Именованная версия сохраняет полный снимок полей. Восстановление сначала добавляет текущий вариант в историю, затем применяет выбранную версию; исходный публичный снимок остаётся отдельным.

Интеграция M5 необязательна: пользователь может выбрать проект и перенести из него услугу, аудиторию, контекст/цель/ограничения и следующий шаг только в поля предпросмотра. Значения не меняют проект и не сохраняются повторно в шаблоне. Без проекта все четыре поля заполняются вручную.

Шаблоны живут в общем IndexedDB-first состоянии пользователя и доступны офлайн. Backup получил формат `sales-os-v8`; экспорт включает рабочие тексты, архив и историю, импорт v1–v7 создаёт для нового поля пустую библиотеку. Объединение одинаковых ID оставляет более свежую редакцию текущей и добавляет конфликтующий вариант в историю; если безопасно сохранить все версии нельзя, импорт отклоняется до записи. Индивидуальный лимит — 250 шаблонов и 100 версий на шаблон; размер всей библиотеки — 3,5 МБ. Более старые версии не удаляются автоматически.

Личный каталог помечен `data-pagefind-ignore`. Тексты шаблонов добавляются в локальный поиск только после явного включения личного поиска; адрес содержит только ID открытого шаблона и не содержит его текст. Пять стартовых вариантов — редакционные черновики, а не экспертная проверка или обещание результата. Для follow-up отдельно указано не писать без допустимого контакта и продолжать диалог после отказа.

## Реализация и проверка

- `sales-knowledge-base/personal-template-starters.json` — единственный источник пяти стартовых примеров. `scripts/template_content.py` проверяет набор категорий, ID, длины и допустимый синтаксис переменных.
- `src/scripts/templates-core.js` задаёт типы, лимиты, проверку данных, независимые копии исходников, слияние, архив и историю.
- `src/scripts/templates.js` содержит редактор только для справочника шаблонов, локальную фильтрацию, предпросмотр, выбор проекта и fallback копирования.
- `src/templates/personal-template-manager.html` переиспользуется Astro и Python fallback; CSS использует существующие токены Geist, границ, фокуса и радиусов.
- Backup v8 интегрирован в общий экспорт/импорт, модульные экспортные кнопки и явный локальный поиск. Старые форматы импорта сохранены.
- Офлайн-manifest и fingerprint production assets включают оба новых скрипта.

Контентный аудит подтвердил 22 модуля, 336 уроков, 72 практики и 33 источника; сгенерировано 467 публичных записей поиска. Оба renderer-а используют один и тот же каркас менеджера и исходный каталог стартовых текстов.

Проверки завершения:

- `npm run test:templates` — прошли нормализация тегов, сохранение снимка, восстановление версии с историей текущего текста, безопасный предпросмотр, защита исходника, архив, слияние конфликтующих редакций, лимиты и контроль ревизии.
- `python -X warn_default_encoding -W error::EncodingWarning tests/test_user_data_embedded.py` — прошли миграция v1, импорт v2 и v7, пустая M6-библиотека при импорте v7, round-trip backup v8 с личным текстом и историей, а также проверки сохранности пользовательских заметок.
- Chromium smoke на `/library/templates/` прошёл путь от стартовой заготовки до предпросмотра и ручного clipboard fallback; проверены блокировка неизвестного маркера, отсутствие исполнения HTML, подстановка полей выбранного проекта без записи в шаблон, сохранение/восстановление версии, архив, избранное и явное включение личного поиска. Копия из публичного источника сохранила ID, название и редакционную версию исходника.
- При ширине 390 и 320 CSS px документ не переполняет viewport. В smoke-сценариях ошибок страницы и консоли не было.
- `npm run check` — 0 ошибок и 0 предупреждений; остались 12 hints о deprecated `beforeunload.returnValue` в исходниках и их сгенерированных копиях. `npm run build` собрал 492 страницы, Pagefind индексировал 467 страниц и 4 587 слов, offline manifest включил 1 050 ресурсов (версия `864f05e8ede2`).
- `npm run build:fallback` — собрал 491 HTML-документ, 467 поисковых записей и 522 offline-ресурса (версия `1f12f1e25d07`).
- `python tests/test_fallback.py` — прошли статический аудит 492 маршрутов, embedded Chromium, backup/data, 175 responsive views, финальный проект и offline worker. `node tests/test_versioned_assets.mjs` подтвердил версионирование новых runtime-скриптов; `node tests/test_offline_worker.mjs` прошёл для Astro и fallback manifests.
- `npm run lint` прошёл проверки контента, синтаксиса и Astro-плагинов, но завершился на уже существовавшем форматировании `src/scripts/app.js`: `prettier --check` также возвращает ошибку на версии этого файла из `HEAD`. Этот отдельный lint-дефект не вызван M6.
- Impeccable detector не нашёл дрейфа в новых компонентах M6. Два предупреждения в общей таблице стилей относятся к обязательному для `DESIGN-vercel.md` шрифту Geist и оформлению Markdown-цитаты.

Скринридер, браузерный zoom 200%, независимая экспертная проверка стартовых формулировок и production deployment этим milestone не заявляются. Все пять стартовых текстов остаются редакционными черновиками; отправки сообщений из продукта нет.
