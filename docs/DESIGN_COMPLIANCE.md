# Дизайн-система: проверка соответствия

Проверяемые токены в `src/styles/app.css` взяты из `DESIGN-vercel.md`: light `#ffffff` / `#000000`, dark `#000000` / `#fafafa`; secondary `#fafafa` / `#0a0a0a`, borders `#e8e8e8` / `#2e2e2e`, текстовые ссылки `#0761d1` / `#3291ff`. Элементы используют спокойные border-основанные поверхности, радиусы 6–8 px, без ярких градиентов и грубых теней.

Переключение темы: Light, Dark, System, с синхронным начальным скриптом для уменьшения мерцания. Mobile sidebar, гибкая сетка, отдельная колонка чтения, TOC на широком экране, `prefers-reduced-motion`, видимый keyboard-focus.

**Не пройдено:** pixel-level визуальная проверка 390/768/1024/1440px в Chromium/Playwright. Браузерная навигация заблокирована политикой среды. Geist/Geist Mono доступны в font stack, но файлы шрифтов не встраиваются; fallback может отличаться по метрикам. Поэтому строгая визуальная сертификация невозможна на данной стадии.
