## Данные и совместимость

`PracticeWorkspace.astro` переиспользуется практиками и итоговым проектом. Нового хранилища и backend нет. `practiceDrafts` и `practiceAttempts` формата v3 теперь принимают зарезервированный `FINAL_PROJECT`; прежнее поле `notes.FINAL_PROJECT` не переименовано и не перезаписывается. Импорт старых v1/v2/v3 копий сохраняется. Новый экспорт с этапами проекта следует импортировать в актуальную версию приложения: старые версии не гарантируют поддержку этого расширения.

Личный поиск дополнительно ищет текущие структурированные ответы и следующий шаг; они не передаются серверу и не добавляются в адрес страницы. Индексация публичного корпуса остаётся отдельно.

Основная Astro-сборка получает версионированные HTTP-ресурсы. Резервный Python renderer сохраняет относительные адреса для самостоятельной статической поставки; изменения форм, таблиц и интерфейсных подписей перенесены и туда.

## Приёмка

- `npm run check`: 0 ошибок, 0 предупреждений, три прежних hints о deprecated BeforeUnloadEvent.returnValue.
- `npm run lint`, `npm run build`, `npm run test:quality`, `npm run test:fallback`: PASS.
- Production-preview E2E: 54 сценария прошли с учётом адресных повторов после исправлений тестовых fixtures (52 в заключительном полном прогоне и 2 при повторе; ошибка записи PNG отдельно перестала воспроизводиться). Набор включает включая Pagefind, все 482 маршрута, офлайн, квоты, миграции, импорт, конфликты двух вкладок, навигацию и новые исправления. Прежние проверки интерфейсного текста/короткого offline fixture и инъекции квоты обновлены под новый контракт; продуктовые проверки сохранены.
- Responsive: 35 маршрутов × 5 ширин = 175 представительных состояний, дополнительно 72 практики × 2 мобильные ширины = 144 состояния, без document overflow.
- Встроенный браузер: desktop-модуль и урок/оглавление, мобильная практика/рубрика, глоссарий, итоговый проект; светлая и тёмная темы. Персональные production-записи пользователя не редактировались.

Репрезентативные новые снимки: [screenshots/visual-audit-2026-10-09/](screenshots/visual-audit-2026-10-09/). Политика HTTP-кеширования сверена с [документацией Vercel](https://vercel.com/docs/caching/cache-control-headers); фактические заголовки опубликованного релиза проверяются отдельно от локального preview.

## Открытые границы production-приёмки

430 основных учебных материалов остаются редакционными черновиками: независимая полная редакционная проверка выполнена для 0/430. Автоматические проверки структуры не заменяют её. Ручная речь NVDA, физический телефон, browser-native zoom и увеличенный системный текст не проверены. Эти ограничения прежнего release gate остаются открытыми; техническое выполнение V01–V20 их не закрывает.
