# Иконки интерфейса

Все 15 пиктограмм используют официальные SVG Lucide, локально сохранённые в `src/lib/icons.json`. Исходный commit: `a04f228cd01185e09c188b7227b9600c08c565ec` — https://github.com/lucide-icons/lucide/tree/a04f228cd01185e09c188b7227b9600c08c565ec/icons. Лицензия ISC/MIT с уведомлениями: `public/assets/lucide-LICENSE.txt`, поставляется вместе с сайтом и offline-пакетом. Сетевой загрузки иконок или нового runtime-пакета нет.

| Имя приложения | Lucide | Назначение |
| --- | --- | --- |
| home | layout-grid | Обзор приложения |
| map | map | Карта учебной программы |
| book | book-open | Учебные справочники |
| practice | square-check-big | Практические задания |
| search | search | Поиск |

| chevron-down | chevron-down | Раскрытие меню и оглавления |
| checkmark | check | Выбранный вариант темы |

| menu | menu | Открыть мобильную навигацию |
| close | x | Закрыть мобильную навигацию |

Один реестр читают Astro-компонент и резервный Python renderer. JS-списки поиска/закладок клонируют готовый декоративный SVG из общего шаблона оболочки. Неизвестное имя вызывает ошибку сборки, вместо случайной подстановки стрелки. Старые неиспользуемые sun/download/folder из fallback удалены.

Общий viewBox 24×24, currentColor, скруглённые окончания/соединения и штрих 1.7 сохраняют существующий Vercel-стиль. Основной размер 16px; у компактного меню темы 14px, у более детальной шестерёнки 18px. Размер SVG не меняет область нажатия. Иконки декоративные (`aria-hidden`, `focusable=false`); смысл дают подписи ссылок/кнопок. Текстовые стрелки внутри подписей переходов сохраняются как часть текста, отдельно стоящие крестик и шевроны заменены SVG.

Проверено 9 октября 2026: production build (482 страницы), Astro check, lint, responsive-проверки, offline worker и полный набор fallback-проверок проходят. E2E проверяет центр SVG и кнопки настроек, смысл навигационных иконок, поиск, закладки, мобильное меню и оглавление в обеих темах. Отдельно пройдена установка полного production offline-пакета с поиском и открытием уроков без сети. Встроенный браузер: desktop 1440×900 и mobile 390×844, ошибок в консоли нет.
