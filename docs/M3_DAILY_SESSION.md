# M3 — Занятие на сегодня

Дата: 2026-10-09. Область: M3 из FEATURE_ROADMAP.md и самостоятельная проверка/исправления M2 по прямому поручению владельца. M4–M8 не начинались.

## Готовый пользовательский путь

На главной выберите 10/20/40 минут и необязательную цель (основы, переписка, цена/предложение) → «Начать занятие» → подтвердите составление плана → откройте материал в новой вкладке → выполните конкретный небольшой шаг → явно отметьте результат в занятии → завершите и получите следующий шаг. «Продолжить сохранённое» открывает последний план; историю можно переключать на экране занятия.

Каждый пункт содержит материал, действие, основание выбора и примерный диапазон времени. При первом посещении нет обязательного onboarding. Если пройденного материала и ручных повторов ещё нет, повторение не выдумывается: это явно объяснено, доступны новый материал и практика.

План можно поставить на паузу, продолжить, заменить невыполненный пункт или пропустить его. После обработки всех пунктов доступно завершение; итог показывает выполненное/пропущенное и один следующий шаг. Необязательная оценка посильности остаётся только на устройстве. Пропуски не создают долг, штрафы или требования заниматься каждый день.

## Правила и границы

- Сначала наступивший ручной повтор по dueAt; при его отсутствии — ранее пройденное. Будущие сроки не переносятся.
- Новый материал выбирается по цели, уровню и порядку программы; ещё не завершённые материалы приоритетнее завершённых. Цели группируют существующие модули; при исчерпании подходящих незавершённых тем доступны следующие по программе.
- Практика — черновой ответ по одному критерию, а не обещание выполнить большое задание целиком. Разбор теории — один смысловой раздел и собственный пример.
- После прохождения всей программы предлагаются повторение и применение знакомого к новой ситуации; из завершённых приоритетны материалы, которые дольше не включались в занятия, чтобы не возвращать один и тот же первый урок. Никакие ручные статусы курса не сбрасываются.
- Диапазоны в today-core.js — авторские ориентиры отдельных действий. Их верхние границы: 3/3/4, 5/7/8 и 6/15/19 минут для трёх типов шагов. Сумма не превышает 10/20/40. Это не измеренная скорость чтения и не гарантия длительности.
- Не выбираются одинаковые материалы в одном плане. Замена исключает уже использованные варианты данного пункта и соседние материалы. При исчерпании вариантов показана причина, тот же пункт не подставляется.
- План — сохранённый снимок, не перестраивается при reload или изменении статусов курса. Новые статусы учитываются при явной замене/создании нового занятия. Новое занятие не стирает старое.
- Отметка «Шаг выполнен» означает только выполнение указанного действия. Освоение урока, самопроверка практики и завершение ручного повтора подтверждаются в соответствующем разделе отдельно.
- День рассчитывается по локальному календарю; пояс сохраняется в снимке. После полуночи или смены пояса появляется пояснение, старое занятие можно продолжить. Новое создаётся только явно.
- Изменения записываются атомарно поверх актуального состояния user-store. Разные выполненные пункты двух вкладок сохраняются. Устаревшее повторное действие по уже изменённому пункту отклоняется с объяснением.
- Никакого backend, аккаунта, AI, новых зависимостей или отправки пользовательского текста. Скрытая аналитика отсутствует; эффективность обучения не заявляется.

## Данные и совместимость

Единый IndexedDB-first user-store, схема базы v3 без нового object store. Backup v5 добавляет today.preferences и today.plans. Импорт v1/v2/v3/v4/v5, merge/replace и общие точки восстановления сохранены. Старые копии получают пустой блок today; merge не удаляет текущие занятия. Конфликт импортируемого UUID сохраняется второй записью, повторный импорт не дублируется.

Лимиты: 365 занятий, максимум три пункта, до 2 млн символов сериализованного блока today и общий файл импорта до 8 MB. Превышение отклоняется без обрезания. Автоматического удаления истории нет; при заполнении архива создание нового занятия останавливается с объяснением. Управление архивами за пределами этого объёма — дальнейшее расширение.

При недоступном постоянном хранилище интерфейс предупреждает о работе в памяти и предлагает скачать копию прямо на странице. Нельзя обещать восстановление временной памяти после закрытия вкладки.
