# Работа с материалами

Контент в `sales-knowledge-base/modules/{slug}/theory`, `practice`, `00-module.md`. Каждый материал: YAML frontmatter с `id`, `title`, `module`, `kind`, `level`, `group`, `status`, `updated`, `sources`, `related_practice`, далее стандартный Markdown. Изменения исходного текста сохранять в Markdown, а не в сгенерированном HTML.

Новая тема требует добавления/корректировки карты исходного роадмапа в `legacy-index.html` или обновления правил валидатора — текущие подсчёты намеренно фиксированы. Ссылки на другие `.md` автоматически преобразуются в маршруты сайта; URLs на HTTPS открываются в отдельной вкладке.

Никаких копий чужих полных книг/транскриптов. Редакционный статус меняется только после документально зафиксированной проверки первоисточников и содержимого. Изменения переносятся через `python scripts/audit.py && python scripts/build.py`.
